# Contract: 編碼對照表 CSV 格式

本檔案是「去識別化 → 還原」的唯一憑證（constitution 原則 II），格式一經釋出即不可破壞性變更。

## 格式

- 編碼：UTF-8 **含 BOM**（`EF BB BF`），確保 Excel 開啟中文不亂碼。
- 換行：`\r\n`（RFC 4180）；解析時同時接受 `\n`。
- 引號規則：RFC 4180——欄位含逗號、雙引號或換行時以雙引號包裹，內部 `"` 跳脫為 `""`。

## 欄位（首列為 header，順序固定）

```csv
code,category,original
a3f9c2,姓名,王小明
7b21e8,身分證,A123456789
c882d1,地址,"台北市信義區市府路45號, 8樓"
```

| 欄位 | 說明 | 驗證（還原端） |
|------|------|----------------|
| code | 6 字元小寫 hex | 必填；全檔不可重複，重複 → 拒絕還原（FR-025） |
| category | 類別文字 | 必填（還原時僅供人閱讀，不參與比對） |
| original | 原始值 | 必填（可為任意文字，含換行） |

## 解析相容性規則

- 欄位以 header 名稱對應，不以位置——允許未來在尾端**新增**欄位（如 fileName），舊檔仍可還原。
- 缺 `code`/`category`/`original` 任一 header → 格式錯誤，拒絕還原並顯示明確訊息（FR-025）。
- 空列忽略。

## 檔名慣例

`<原檔名去副檔名>.mapping.csv`（例：`report.docx` → `report.mapping.csv`）。僅為慣例，還原不依賴檔名。
